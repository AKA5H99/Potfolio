# Akash Sharma Portfolio

Static portfolio site showcasing game-development work and project write-ups.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static-file server.

## Structure

- `index.html` — portfolio homepage
- `*.html` — individual project pages
- `assets/css` — shared styles
- `assets/js` — homepage interactions
- `assets/vendor` — third-party libraries used by the site
- `assets/videos`, `assets/gif`, `assets/img` — portfolio media
